## 宣发核心卖点提炼 (Core Pitches)

1. **彻底绕过弹窗阻塞**：通过 `SIGTERM` 优雅通知 -> 400ms 宽限期轮询 -> `SIGKILL` 兜底强退，直接绕过应用未保存时的弹窗卡死。
2. **访达 (Finder) 优雅退出**：独家 AppKit 退出协议，彻底解决传统终端 `killall Finder` 造成的“闪退又瞬间弹回”复活循环。
3. **四级白名单防御体系**：核心系统 (L1)、当前会话终端与 IDE (L2)、常驻设施与输入法 (L3)、用户配置 (L4)，绝不误杀开发环境与系统组件。
4. **原生果味质感**：基于 SwiftUI 原生打造，采用暗屏监视器基底、微网格与微浮雕操作，支持 24 种语言自动适配。
5. **双模态操作**：菜单栏鼠标一键点击 + 纯键盘终端向导 (`mtc -i`)，满足不同工作流偏好。
