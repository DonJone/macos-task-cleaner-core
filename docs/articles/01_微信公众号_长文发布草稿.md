## 正文内容

### 引言：每个 Mac 用户都曾经历过的“桌面崩溃时刻”

在日常开发、工作或高强度多任务处理时，很多 Mac 用户都会遇到类似的窘境：

在经过一整天的摸鱼、查阅资料与高强度编码后，屏幕下方 Dock 栏上亮着密密麻麻的小黑点：几十个浏览器窗口、几个卡住的文档编辑器、正在报错的通讯软件、挂起的大型软件……

想要一次性退出所有前台应用，通常有三种无奈的选择：
1. **挨个 `⌘Q` 狂按**：遇到未保存的应用，必然弹出一个居中的模态对话框问你“是否保存修改？”，如果你点击取消，整个批量关闭流程立刻被硬生生中断；
2. **打开活动监视器 (Activity Monitor)**：在成百上千个复杂的系统守护进程（Daemon）、XPC 服务中小心翼翼搜索目标，稍有不慎就误伤系统底座；
3. **在终端粗暴 `killall`**：直接下发信号，很容易误杀自己当前正在执行编译的终端窗口，甚至导致访达 (Finder) 闪退后立刻被 launchd 强行拉起，关了跟没关一样。

为了彻底、优雅地终结这个痛点，**Task Cleaner for macOS** 正式诞生。

### 一、什么是 Task Cleaner？

**Task Cleaner** 是一款面向 macOS 打造的高性能、非侵入式前台任务清理与白名单管理工具集。

它不是一个粗制滥造的脚本，而是一套完整的工程级解决方案：
* **原生轻量**：驻留在 macOS 顶部菜单栏，采用纯原生 SwiftUI + AppKit 开发，没有笨重 Electron 的几百兆内存占用，极其省电；
* **硬核内核**：底层采用 Rust 编写的高精度引擎（`macos-task-cleaner-core`），毫秒级感知前台进程并按阶梯下发退出控制；
* **双模态体验**：既可以在状态栏一键清场，也为键盘党提供了专用的终端交互式向导（`mtc -i`）。

---

### 二、三大核心技术突破：为什么它比传统工具更好用？

#### 1. 非侵入式分级降级清场，绕过流氓弹窗

传统应用在收到退出事件时，往往会触发自身的事件循环，从而弹出“是否保存”等模态确认窗口。如果用户离开电脑或不想理会，流程就会卡死。

Task Cleaner 采用精密的 **POSIX 三段式平滑生命周期调度**：
* **第一阶段 (SIGTERM)**：向目标进程下发优雅退出信号，允许应用正常刷新缓冲区并安全释放系统句柄；
* **第二阶段 (宽限期轮询)**：核心引擎在后台以毫秒级频率实时轮询目标 PID，默认提供 400ms 的平滑自愿退出时间窗；
* **第三阶段 (SIGKILL 兜底)**：一旦应用被模态弹窗或卡死逻辑阻塞，在超时后立即无感知下发强退信号，彻底终结卡顿。

#### 2. 独家解决访达 (Finder) 退出防自启循环

不少开发者尝试在终端清理 Finder 时，都会发现一个怪异现象：Finder 窗口关了一下、桌面闪烁黑屏，但一秒钟后又立刻自动弹了回来。

这是因为 macOS 系统调度机制中，`launchd` 守护进程将常规 POSIX 信号判定为非正常崩溃（Crash），因此会根据 KeepAlive 配置立即强制拉起 Finder。

Task Cleaner 针对 Finder 实现了独有的 **AppKit 原生退出协议**：
通过直接调用 `NSRunningApplication.terminate()` 通知系统，使其明确标记为“用户主动发起的合规退出”，确保访达平稳离线，杜绝反复复活。

#### 3. 四级白名单防御矩阵，绝不误杀当前工作区

很多清理脚本最让人头疼的就是“误杀终端”——在 iTerm2 里跑脚本，脚本第一件事就是把 iTerm2 自己给关了。

Task Cleaner 构建了严密的四级白名单防御体系：
* **L1 系统核心层 (Core OS)**：绝对免疫 Dock、WindowServer、SystemUIServer、ControlCenter 等关键中枢；
* **L2 会话终端层 (Context Shell)**：自适应递归遍历调用者进程树，自动豁免当前调用者 PID、父进程 PPID，并对 Terminal、Ghostty、iTerm2、Alacritty、VS Code 等开发环境进行自动化保护；
* **L3 常驻设施层 (Persistent Utilities)**：智能识别 Raycast、Alfred、Rectangle、输入法（鼠须管、搜狗）与系统监控组件；
* **L4 用户配置层 (User Config)**：用户可在面板上点击盾牌图标，或在 `~/.config/mtc/config.toml` 中自定义永久白名单规则。

### 三、终端极客的利器：交互式向导 `mtc`

除了优雅的原生状态栏浮窗外，配套的命令行工具 `mtc` 为终端重度用户提供了极佳的操控体验：

* **交互式向导 (`mtc -i`)**：无需记忆复杂参数，终端会列出当前所有前台软件及其 PID 与白名单状态。输入 `w 2` 直接加白，输入 `t 1` 本轮跳过，按 `c` 平稳清场，按 `f` 秒杀强退；
* **预检模式 (`mtc --dry-run`)**：在真正结束前，先打印分析报告，看看有哪些软件命中清理、哪些受到保护；
* **结构化 JSON 支持 (`mtc --json`)**：可轻松接入 Raycast 脚本、Alfred Workflow、Keyboard Maestro 或系统快捷指令（Shortcuts）。

### 四、原装果味设计与多语言支持

为了让工具与 macOS 整体视觉高度统一，Task Cleaner 严格遵从 Apple Human Interface Guidelines：
* 状态栏常驻纯净镂空图标，右上角实时动态感知活跃前台任务总数；
* 弹窗采用深色监视器屏幕基底、微网格纹理与精致的微浮雕操作质感，与 macOS 终端及活动监视器一脉相承；
* 智能适配 24 种国际主流语言，随系统语言自动无缝切换；
* 完美支持 macOS 13+ 原生 `SMAppService` 开机自启动，零多余后台常驻常年开销。
